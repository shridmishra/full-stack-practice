# React Interview (Vite JSX)

This folder is a small Vite + React (JSX) project with assignment stubs in `src/assignments/` and reference solutions in `src/solutions/`.

## Topics Covered (5 Assignments)

1. **Components, Props & Composition** — JSX, function components, children, composition patterns
2. **State, Reducer & Forms** — useState, useReducer, controlled forms, validation
3. **Effects, Data Fetching & Custom Hooks** — useEffect, fetch patterns, cleanup, building custom hooks
4. **Context, Custom Hooks & Advanced Patterns** — Context API, useContext, building reusable hooks
5. **Refs, Performance & Optimization** — useRef, forwardRef, React.memo, useMemo, useCallback

## Quick start

1. From this folder run:

```bash
cd react-interview
npm install
npm run dev
```

2. Open the dev server URL (usually http://localhost:5173).

## Notes

- `src/assignments/` contains stubs that throw `Not implemented`. These are intended for interview practice.
- `src/solutions/` contains working reference implementations.
- Each assignment has a corresponding `.md` file with references and task descriptions.
